# Módulo 0.3 — Diseño UX/UI

> Proyecto: Random Dreams
> Estado: completo (v1)
> Decisiones de este módulo: dirección visual **neutral minimalista** y prototipo **HTML + Tailwind** en el repo.

---

## 1. Objetivo

Definir la experiencia de usuario y el sistema de diseño base: wireframes de las 5 pantallas clave, design tokens y componentes UI reutilizables, y un prototipo navegable.

## 2. Dirección visual

**Neutral minimalista** (decidida por el usuario).

- Fondos claros y neutros; el contenido (texto + imagen generados) es el protagonista.
- Un único color de acento (`violet`) para acciones primarias, enlaces y foco.
- Colores de estado semánticos para el pipeline de generación.
- Tipografía: una sola familia sans (Inter), jerarquía por peso y tamaño.
- Sin elementos decorativos pesados; máximo espacio en blanco y bordes sutiles.

## 3. Flujo de pantallas

```
/catalogo ─▶ /producto/[slug] ─▶ /checkout/[orderId] ─▶ /generacion/[orderId] ─▶ /resultado/[orderId]
   (catálogo)   (detalle + form)   (confirmación)         (estado de generación)      (texto + imagen)
```

El estado de generación hace **polling** al backend; en error muestra un botón de **reintento manual** (decisión 0.1). `resultado` es la única pantalla con descarga.

## 5. Sistema de diseño base

### 5.1 Tokens (CSS variables)

| Token | Valor | Uso |
|---|---|---|
| `--surface` | `#FFFFFF` | Fondo de página y tarjetas |
| `--mist` | `#F8FAFC` | Fondos alternos / secciones |
| `--line` | `#E2E8F0` | Bordes y divisores |
| `--ink` | `#0F172A` | Texto principal |
| `--muted` | `#64748B` | Texto secundario / hints |
| `--primary` | `#6D28D9` | Acento único (botones, enlaces, foco) |
| `--primary-hover` | `#5B21B6` | Hover del acento |
| `--primary-light` | `#EDE9FE` | Fondos suaves del acento (badges) |
| `--success` | `#059669` | Estado `completed` |
| `--warning` | `#D97706` | Estado `processing` / `queued` |
| `--danger` | `#DC2626` | Estado `error`, acciones destructivas |
| `--info` | `#2563EB` | Información |

Tipografía: **Inter** (sans única), escala base 16 px.
Escala: `display 30`, `h1 24`, `h2 20`, `h3 16`, `body 14–16`, `caption 12–13`.
Espaciado: escala de 4 px (`4, 8, 12, 16, 24, 32, 48, 64`). Radio: `6 / 10 / 14 / full`. Sombras: sutiles, sin elevación excesiva.

### 5.2 Componentes UI

| Componente | Especificación mínima |
|---|---|
| **Button** | Variantes `primary / outline / ghost / danger`; tamaños `sm / md / lg`; estados `loading` (spinner) y `disabled`. Primary = `--primary`. |
| **Field** | Wrapper con `label` + `hint` + `error`; el error resalta el borde con `--danger` y muestra mensaje. |
| **Input / Select / Textarea** | Alto 40 px, borde `--line`, foco con anillo `--primary` (2 px). Selects con placeholder "Seleccioná…". |
| **MultiSelect (chips)** | Opciones como chips con `✓` (para listas tipo "cosas que nunca te dijiste"). |
| **ProductCard** | Ilustración, nombre, descripción de 1 línea, CTA `[Crear]`. Grid 1/2/3 columnas. |
| **StatusBadge** | `queued` (neutral), `processing` (warning + spinner), `completed` (success), `error` (danger). |
| **PipelineSteps** | Lista de pasos de generación con estados (✓ / spinner / pendiente) — wireframe 4.4. |
| **ResultViewer** | Dos paneles: imagen (`.png`) y texto (`.txt`) en scroll; botones de descarga. |
| **Navbar / Footer** | Logo, enlaces (Catálogo, Cuenta), minimales y neutros. |

### 5.3 Accesibilidad y responsive

- Mobile-first: grid 1 columna (mobile) → 2 (tablet) → 3 (desktop) para el catálogo.
- Formularios: `label` asociado, `aria-required`, mensajes de error con `role="alert"` / `aria-live`.
- Estados del pipeline legibles sin color (texto + icono, no solo color).
- Foco visible con anillo `--primary`; navegación completa por teclado.

## 6. Prototipo navegable

Ubicación: **`app-random-dreams/prototype/`** (HTML + Tailwind CDN, sin build).

| Archivo | Pantalla |
|---|---|
| `index.html` | Catálogo |
| `producto.html` | Detalle + Formulario (ejemplo: Souvenir de Vida Paralela) |
| `checkout.html` | Confirmación |
| `generacion.html` | Estado de generación (simulado) |
| `resultado.html` | Resultado (.txt + .png) |

Comparten `styles.css` (tokens) y `tailwind-config.js`. Abrir `prototype/index.html` en el navegador para recorrer el flujo.

Notas:
- La pantalla `generacion` es una **simulación estática** (polling real se implementa en el MVP).
- El ejemplo de formulario usa los campos reales del Souvenir; los demás productos reutilizan el mismo patrón (`Field`).

## 7. Decisiones resueltas

| # | Decisión |
|---|---|

| 2 | Prototipo: **HTML + Tailwind** versionable en el repo (`prototype/`). |
